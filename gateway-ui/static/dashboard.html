      Авто-обход beta
      
          
      Отдельный список адресов через VPS — не трогает основной. Два независимых тумблера:
      
          
      
            
            
          
      
          
      
        
      

        
      
          
      Добавить вручную
      
          
      Домен (example.com, geosite:тег) или IP/подсеть (1.2.3.4, 1.2.3.0/24). Пачкой — по одному в строке или через запятую.
      
          
          
      
          
      
        
      

        
      
          
      
            
      Список авто-обхода (0)
      
            
      
              
              
            
      
          
      
          
      Домены и IP, добавленные сюда (вручную или автоматически). Обновляется само каждые 15 c. Можно удалять.
      
          
      
            
            
            
          
      
          
        
        
        
        
        

        
        
          
        
            
        
              
        Перепроверка списка
        
              
            
        
            
        Раз в заданное время пробит весь список напрямую и через VPS. Если адрес снова работает напрямую два прогона подряд — убирает из списка. Работает независимо от тумблера авто-обхода: даже если обход выключен, список чистится и сохраняется.
        
            
        
          
        

          
        
            
        Расписание
        
            
        
              
              
              
            
        
            
        Больше воркеров — быстрее большой список (30 хватает; 1000 адресов ≈ 2–4 мин).

        Whitelist
        
          
        Домены, которые детектор вообще не анализирует (ни как кандидат на обход, ни тенью в лог).
            Сид `.ru`/`.su`/`.рф` заводится автоматически при каждом старте UI. Курируемый список
            (xray/domains/*.txt) приоритетнее — whitelist на такие домены не действует.
        
          
        
          
        
            
            
            
            
          
        
          
        
        
        
      
        

      
        
        
        
          
        Пресеты zapret
        
          
        Стандартные (flowseal, 20 шт.) пробуются "мозгом" всегда первыми. Custom — свои,
            добавленные вручную; пробуются, только если ни один стандартный не подошёл, доверенные и
            успешные — первыми среди custom.

        Game Mode
        
          
        Бланкет-ACCEPT для эфемерных портов игровых серверов (1024-65535) —
            трафик в этих портах вообще не анализируется и не десинхронизируется (без VPS, без zapret),
            чтобы не добавлять задержку. UDP ограничен сверху 49999 — диапазон 50000-65535 закреплён
            за голосом Discord (VPS-туннель) и Game Mode его не трогает.
        
          
        
            
            
          
        
          
        
        
        
      
        

      
        
        
        
          
        Реклама (AdGuard Home)
        
          
        DNS-блокировка рекламы/трекеров на самом шлюзе — работает на всех
            устройствах дома автоматически, ничего ставить не нужно. Полная панель (фильтры,
            список клиентов, журнал запросов) — отдельно, ссылка ниже.
        
          
        AdGuard Home недоступен — проверьте сервис на шлюзе.

        Мониторинг zapret
        
            
          
        
          
        Демоны nfqws, очереди трафика и сервисы. Обновляется каждые 3 c. Только просмотр.
        
        
        
        
        
          
        Мозг: группы по стратегии
        
          
        С 2026-07-23 (T-consolidate) — один демон обслуживает ВСЕ домены с одинаковой рабочей стратегией, не по домену на демон. Кликни группу, чтобы увидеть её домены.
